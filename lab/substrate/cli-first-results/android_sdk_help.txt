Usage: android sdk [-h] [--ignore-outdated-xmls] [--platform=PARAM] [COMMAND]
Manage the Android SDK installation. Includes commands to install, update,
remove, and list available and installed SDK packages

Options:
  -h, --help                  Show the help message for this command
      --ignore-outdated-xmls  When installing or updating packages, do not
                              update other packages xmls
      --platform=PARAM        Target platform <os>_<arch> (e.g. linux_x86_64,
                              mac_arm64, windows_x86), defaults to current host

android options:
      --sdk=PARAM             Path to the Android SDK
  -v, --verbose               Enable verbose output for troubleshooting
  -V, --version               Print version information and exit
Commands:
  install  Install SDK packages
  list     List installed and available SDK packages
  remove   Remove packages from the SDK
  update   Update one or all packages to the latest version
